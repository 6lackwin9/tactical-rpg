# Task queue (planner-owned; agents read only their task)

Statuses: `idea` (brainstorm only), `spec` (spec written, awaiting approval), `approved`, `in-progress`, `review`, `done`. Lanes: `logic`, `asset`, `design`, `balance`. Layer (since SPLIT1-9): `engine` (`engine/`, game-agnostic), `kit` (later), `game` (`games/<id>/`), or `engine + game` when a task changes both; its change lands in that layer (the change-reviewer checks it). A task may start when everything in `Depends on` is `done` (schema-first tasks release their asset lane as soon as the schema slice is merged). Done rows move to `docs/archive/TASKS_DONE.md` (cloud: as a `Done:` line in the task commit, written by the Merge & Release thread; decision "Shared logs"). An `in-progress` row names its branch in the Status cell, so either environment can resume it (`docs/workflow/README.md`).

Transition to the Aegis engine (2026-10-19, decision "Engine transition (user 2026-10-19)"): rows written before it name Godot paths in Touches and specs (`scripts/**`, `scenes/**`, `.gd` files, `project.godot`). Those files are frozen in `legacy/`; the rules they name are ported to the engine (map: `engine/docs/PORT_NOTES.md`). The planner re-scoped every open row's Touches and dependencies to the engine on 2026-10-19 (`docs/specs/RESCOPE1.md`); specs still name the Godot classes the engine ports (map: PORT_NOTES). The PORT-* rows are engine gaps the re-scope found.
