# Project structure: current and reserved

Builders put code where this file says; if a path is missing, ask Design before creating it. Update this file when a module, crate, or folder is added. Since 2026-10-19 the game runs on the **Aegis** Rust engine (`engine/`); the frozen Godot build lives in `legacy/` (`engine/docs/PORT_NOTES.md` maps ports). Detailed per-PR crate/test changelogs are archived in [STRUCTURE_NOTES_2026_11A.md](archive/STRUCTURE_NOTES_2026_11A.md).

**Three-layer rule (`fc.sh layers` / `SPLIT1`)**: `engine/` is 100% game-agnostic and never names a game or lore word; `kits/rpg/` holds genre rules (`rpgkit_*` + kit assets) and never names Emberwake worlds, classes, or `games/emberwake/lore_words.txt` words; `games/emberwake/` holds game façades, GUI, content, assets, and docs.

## Code conventions

- Names: files/modules `snake_case`; types/traits `PascalCase`; functions/variables `snake_case`; constants `UPPER_SNAKE_CASE`.
- Keep Godot port symbol equivalents documented in `engine/docs/PORT_NOTES.md`.
- Plan then resolve: planning queues deterministic commands without mutating battle state; game logic never reads frame timing or window state.
