## Goal

Exercise every path of the art pipeline with shipped data, without changing how anything looks: one alias for the CLN-15 reuse, a few file overrides that are PNG exports of today's placeholders, and the `icon_id` that keeps the shortsword icon once S14-L1 removes the deprecated category branch.

## Schema contract

None (uses the S14-L1 manifest fields). All rows `origin: user` except where the table says `system`.

## Acceptance (rule-derived)

1. `AssetCatalog.validate_all()` and `ContentCatalog.validate_all()` are `{}` after each commit.
2. `AssetRegistry.resolve("unit", "goblin_brawler", "token")` gives `source == "template"` and key `berserker`; the goblin_brawler token texture equals the berserker one (same image data).
3. The four file rows resolve with `source == "file"`; their composed textures match the template textures within 2 per channel on every pixel (export round trip), so nothing looks different.
4. After commit 2, `ItemArt.icon_key` of `wpn_shortsword` is `shortsword` with the S14-L1 category branch removed.
5. Seed listed in `data/seeds/README.md` with its task id.
