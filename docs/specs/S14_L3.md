## Goal

Sound plays by key through the asset registry, never by path; a missing sound is silent and warns once; headless runs, tests and the sim never create audio players. Volumes come from the settings file per bus.

## Schema contract (logic lane, schema first: yes)

### Buses (`default_bus_layout.tres`)

| Bus | Send | Default volume (linear) |
| --- | --- | --- |
| `Master` | - | 1.0 |
| `Music` | Master | 0.8 |
| `SFX` | Master | 0.8 |
| `UI` | Master | 0.8 |

Volumes are placeholders for the polish pass. Linear values map to dB with `linear_to_db` (0.0 = mute, `AudioServer.set_bus_mute` true).

### Sound event keys (`SoundEvents`, const tables)

`sfx` namespace keys (manifest rows of S14-A2; any key may be missing):

| Key | Fired by |
| --- | --- |
| `hit` | presenter preset `hit` |
| `crit` | preset `hit` when `"CRIT" in entry.outcome_tag` (replaces `hit`) |
| `mitigated` | preset `mitigated` |
| `heal` | preset `heal` |
| `buff` | preset `buff` |
| `debuff` | preset `status` on a debuff (`StatusRegistry` kind) |
| `defend` | preset `defend` |
| `move_step` | preset `move` |
| `defeat` | preset `defeat` |
| `ui_click` | `AudioDirector.ui("click")` from views (buttons opt in; none wired here except the playback controls) |
| `ui_confirm`, `ui_back`, `ui_error` | reserved for UI1-L views |

`SoundEvents.FOR_PRESET: Dictionary` maps preset id to key (`attack_melee`, `attack_ranged`, `float_text`, `status` on a buff map to "" = no sound).

### `SoundBank` (static, `RefCounted`)

| Function | Rule |
| --- | --- |
| `stream(key: String) -> AudioStream` | `AssetRegistry.stream("sfx", key)`; null when unresolved; the first null per key per session prints `push_warning("SoundBank: no sound for '%s'.")`, later ones are silent |
| `has(key) -> bool` | resolves to a stream |
| `clear_warned()` | test helper |

### `AudioDirector extends Node`

| Member | Rule |
| --- | --- |
| `static func enabled() -> bool` | false when `DisplayServer.get_name() == "headless"` (tests, `tools/fc.sh` suites and the sim all run with `--headless`) |
| `_ready()` | when enabled, creates `SFX_VOICES` (placeholder 8) `AudioStreamPlayer` on bus `SFX` and `UI_VOICES` (placeholder 2) on bus `UI`; when disabled creates none |
| `play_sfx(key)` | stream from `SoundBank`; null -> return; else the first idle voice plays it; all busy -> the voice that started earliest restarts with it |
| `ui(event)` | `play` on the UI voices with key `"ui_" + event` |
| `connect_presenter(p: CombatPresenter)` | connects `fx_played` to `play_sfx(SoundEvents.key_for(preset, entry))` |
| `apply_volumes()` | reads `SettingsFile` audio keys, sets the four bus volumes |
| `voice_count() -> int` | for tests |

Music is not built (no players, no API) beyond the `Music` bus.

### Settings file (2.4 shared contract)

`SettingsFile` (`scripts/game_state/settings_file.gd`, static, `ConfigFile` at `user://settings.cfg`, `use_path(p)` for tests). This task owns the audio keys; UI1-L owns the rest and the screen. Whichever task lands first creates the file with `load()`, `save() -> Error`, `get_value(key, default)`, `set_value(key, value)` and the key table below; the later one only adds keys.

| Key | Type | Default | Clamp |
| --- | --- | --- | --- |
| `audio/master` | float | 1.0 | 0.0..1.0 |
| `audio/music` | float | 0.8 | 0.0..1.0 |
| `audio/sfx` | float | 0.8 | 0.0..1.0 |
| `audio/ui` | float | 0.8 | 0.0..1.0 |

A missing file or key yields the default; a wrong type yields the default and one warning. The settings file is never part of a save slot.

## Rules (logic lane)

1. Keys only: no script outside `SoundBank` names an audio file path.
2. Silent fallback: an unresolved key never errors, never stops presentation, warns once per key per session.
3. Headless: no `AudioStreamPlayer` is created when `enabled()` is false; the sim and the test runner therefore never touch the audio server beyond the bus layout load.
4. One director per main scene: the combat arena and the scene runner each add one `AudioDirector`; the combat arena calls `connect_presenter` on its grid panel's presenter and `apply_volumes` on ready.
5. Placeholder tool `tools/gen_placeholder_sfx.gd`: writes short mono 22050 Hz sine or noise blips as `.wav` (`AudioStreamWAV.save_to_wav`) to `res://assets/audio/sfx/<key>.wav` from args `key wave(sine|square|noise|noise_sine) hz_from hz_to ms envelope(decay|fade|slow) gain_db` (S14-A2 lists the values), and prints `§ wrote <path> <ms>ms`.

### Commits

1. Schema: bus layout, `SettingsFile` audio keys, `SoundEvents`, `SoundBank` (registry lookup + warn once), the tool (releases S14-A2).
2. Playback: `AudioDirector`, presenter connection, scene wiring, suite.

## Acceptance checks (rule-derived; `audio_test_suite.gd`)

1. `AudioServer.get_bus_index` finds `Master`, `Music`, `SFX`, `UI`; each non-master bus sends to `Master`.
2. `SoundBank.stream("no_such_key")` is null; two calls print one warning (counted through a test hook), `clear_warned` resets it.
3. In the headless test run `AudioDirector.enabled()` is false and a director added to the tree has `voice_count() == 0`; `play_sfx("hit")` returns without error.
4. `SettingsFile` in a sandbox path: defaults when missing; `set_value("audio/sfx", 1.7)` then `get_value` gives 1.0 (clamp); round trip through `save`/`load` keeps values; deleting a save slot (`SaveGame.delete`) leaves it unchanged.
5. With a manifest row for `sfx/hit` (sandbox manifest, file from the tool), `SoundBank.stream("hit")` is an `AudioStreamWAV`.
6. `SoundEvents.FOR_PRESET` has an entry for every `FxPresets.PRESETS` id; every non-empty value is a key of the event table.

## Build notes (planner 2026-10-17)

- `AudioDirector.active` (the director last added to the tree) and `AudioDirector.ui_event(event)` let views opt in to UI sounds without a reference; the playback panel plays `ui_click` on every button through it.
- `AudioDirector` skips the SoundBank lookup when it has no voices, so headless runs never warn about missing keys.
- The scene runner's director also calls `apply_volumes` on ready.
- The tool's generator lives in `scripts/audio/placeholder_sfx.gd` (`PlaceholderSfx.write`) so the suite can write a wav into its sandbox; `tools/fc.sh gen_sfx` wraps the tool. Waves `sine|square|noise|noise_sine`, envelopes `decay|fade|slow`, 16-bit mono 22050 Hz, fixed noise seed.
- `SettingsFile.get_float(key)` is a typed helper over `get_value`.

## Out of scope

Music playback and cross-fades, ambience, 3D or positional audio, voice, the settings screen (UI1-L), final sound files (S14-A2 ships placeholders), per-skill sounds.
