# Decisions (settled; do not re-litigate without asking the user)

Index since 2026-10-17 (CLN-10): the decision rows live in one file per system, moved unchanged in their original order: the game's systems in `games/emberwake/docs/decisions/` (since SPLIT1-9), process in `docs/decisions/workflow.md`, superseded rows in `docs/decisions/archive.md`. Read this index plus the file of the system you work on; agents cite a row by its title (for example DECISIONS "BAL2 role answers"), which stays valid in the per-system file. Superseded rows are in `docs/decisions/archive.md` with a "superseded by" pointer; partly superseded rows stay in their system file with a note under the table. New rows go at the end of the matching system file (a new system gets a new file and a line here).

| README | Updated with every change | User standing rule |
| Uncertainty | Check known-issues table; max 2 failed fixes; then ask the user with findings and options. Always ask on design/gameplay choices | User request |
