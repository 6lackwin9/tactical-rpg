# Design calls for your review

The Design Session writes this file (decision "Build feedback on the recommended option (user 2026-11-10)" and `docs/PRINCIPLES.md` Section 0). Whenever an `FB-nn` / `UN-nn` Build item, `.1` spec detail, or `CL-nn` canon gap needs a reversible call while you are away, Design scores candidate options against **`docs/PRINCIPLES.md`** (`P-ARCH`..`P-UI`), applies the lowest-undo-cost principle-aligned option straight away as `[PROVISIONAL]` (in `docs/READY.md`, specs, or `CANON.md`), and logs **architectural / mechanical / rule / UI-contract** calls in `## Open (newest first)` while separating pure **game-data / copy / balance-feel** items into `## Playtest Review Target` (`PRINCIPLES.md` §0.4, user `2026-11-14`). To flip one, say which row and what you want instead; Design then queues the change like any other.

Excluded (always asked first, never applied alone): anything irreversible (push/merge to `main`, `itch.io` deploy, deleting files or branches, external image-generation runs without approval, breaking shipped release saves without migration) or a direct conflict between two `[LOCKED]` rulings.
