# engine/assets

The engine's baseline asset layer (ASSETORG2, `docs/specs/ASSETORG2.md`): the last place every lookup tries, after the
game's `assets/` and its kit's (`kits/<kit>/assets/`). Anything here works for any game; a game or kit overrides a file
by putting its own at the same relative path.

- `fonts/`: the UI font (Open Sans SemiBold, `OpenSans-OFL.txt`).
- `tilesets/common/<tile>/v<n>.png`: the generic terrain set (battles use it until a map names a set; region maps fall
  back to it after the world's own sets). The variant count is the run of files present.
- `audio/sfx/ui_{click,back,confirm,error}.wav`: interface sounds.
- `ui/`: reserved for toolkit glyphs (empty today).

The tiles were generated by `tools/gen_art.py` (ART1-A) and the interface sounds by the PORT-AUDIO tools.
Regenerate the tiles with `python tools/gen_art.py terrain --layer engine --overwrite` (the generator writes the layered
tree; existing files are kept without `--overwrite`). To check a regeneration, write it into an empty folder
(`--root DIR`) and compare it with the committed tree (`tools/gen_art.py --compare DIR`; the tool's header).
