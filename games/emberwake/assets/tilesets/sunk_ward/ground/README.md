# tilesets/sunk_ward/ground: Sunk Ward region-map ground textures (placeholder)

Each `<ground>/v0.png` is a 256 x 256 seamless texture at 32 px per map tile (8 x 8 tiles), drawn under the region
maps by their `ground` grid. Since 2026-11-22 these are the Style 2 set (Gemini items SW-35 and SW-36, Art/UI): one
512 x 512 quadrant per ground, scaled to half. They replace the flat 2026-11-15 fills (decision "Placeholder-first
assets"); finals replace them in place.
