# assets/audio/music

The game's music (S14, MUSIC1): `<key>.ogg` (Ogg Vorbis): `menu_theme` and the world tracks; the mood loops (`combat`, `boss`, `town`, `shop`, `danger`, `travel`) are the RPG kit's (`kits/rpg/assets/audio/music/`, ASSETORG2-K). The engine plays `music/<key>.ogg` directly (PORT-AUDIO), so a new track needs only its file; it is found over the asset layers (ASSETORG2: the game's, the kit's, the engine's `audio/`).

`menu_theme` (since 2026-11-11) is a Flow Music track (Lyria 3.5), imported by `python -m tools.mock_ui.music` as the whole song with a 2.5 s pause before it restarts; its prompt and import record is `art_src/music/menu_theme.json` (ART_UI_STUDIO 3.9). `sunk_ward_town` (the hub; MUSIC1's `town` context for the Sunk Ward) is a Flow Music cover of it, record `art_src/music/sunk_ward_town.json`. `sunk_ward_combat` (MUSIC1's `combat` context for the Sunk Ward) is a 48 s section loop of a Flow Music battle take's bass and other stems, record `art_src/music/sunk_ward_combat.json`. `sunk_ward_combat_2` and `sunk_ward_combat_3` are its variants (whole songs with several stages; records beside it); they play only once the engine picks among a key's `<key>_N` variants, a request in ART_UI_STUDIO 3.9. Do not regenerate `menu_theme` with `tools/gen_music.py`, which would overwrite it with the old synthesized loop. The other loops (`ashlands`, `iron_reaches`, `tidewrack`, `combat`; MUSIC2: `town`, `danger`, `shop`, `travel`, `boss`) are still generated by `python3 tools/gen_music.py [key ...]` (numpy + ffmpeg with libvorbis): original tracks synthesized from notes, rendered as one circular buffer so the loop has no seam. `MusicDirector` picks the track (`games/emberwake/docs/specs/MUSIC1.md`); a region gets its own track by adding a row whose key is the region id.
