# assets/audio/music

Music files (S14, MUSIC1): `<key>.ogg` (Ogg Vorbis). The engine plays `music/<key>.ogg` directly (PORT-AUDIO), so a new track needs only its file; `data/assets/manifest.json` is the Godot-era index and the engine does not read it.

The loops (`menu_theme`, `ashlands`, `iron_reaches`, `tidewrack`, `combat`; MUSIC2: `town`, `danger`, `shop`, `travel`, `boss`) are generated by `python3 tools/gen_music.py [key ...]` (numpy + ffmpeg with libvorbis): original tracks synthesized from notes, rendered as one circular buffer so the loop has no seam. `MusicDirector` picks the track (`games/emberwake/docs/specs/MUSIC1.md`); a region gets its own track by adding a row whose key is the region id.
