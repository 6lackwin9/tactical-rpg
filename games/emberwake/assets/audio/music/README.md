# assets/audio/music

Music files (S14, MUSIC1): `<key>.ogg`; each needs a row in `data/assets/manifest.json` (`data/seeds/music1_a.gd`).

The loops (`menu_theme`, `ashlands`, `iron_reaches`, `tidewrack`, `combat`; MUSIC2: `town`, `danger`, `shop`, `travel`, `boss`) are generated by `python3 tools/gen_music.py [key ...]` (numpy + ffmpeg with libvorbis): original tracks synthesized from notes, rendered as one circular buffer so the loop has no seam. `MusicDirector` picks the track (`docs/specs/MUSIC1.md`); a region gets its own track by adding a row whose key is the region id.
