## Goal

Content refers to art by key; a key resolves through one registry to a file override (manifest row), else the generated SVG placeholder, else a namespace fallback, never null. Real art can replace placeholders by adding a file and a manifest row, with no code change. Team identity stays readable for file art. Skills and statuses get generated placeholder icons.

## Schema contract (logic lane, schema first: yes)

### Manifest file

`res://data/assets/manifest.json`: `{"kind": "asset_manifest", "version": 1, "entries": [...]}`. `AssetCatalog` copies the QuestCatalog contract (`scripts/quests/quest_catalog.gd`): state on the Engine singleton (`STATE_KEY` `&"asset_catalog_state"`), `DEFAULT_PATH`, `use_path(path)` for tests (never write `res://` from a test), `clear_cache`, `reload_from_disk`, `load_errors`, `save_blocked`, `is_dirty`, `normalize`, `entries`, `ids`, `has`, `get_entry`, `validate_entry(entry, current_id = "")`, `upsert(entry, replace_id = "") -> Array[String]` (nothing changes on error), `remove(id) -> String`, `validate_all`, `warnings_for`, `warnings_all`, `save`. A file that loaded with errors refuses to save.

### Entry fields

| Field | Type | Default | Validation (exact message) |
| --- | --- | --- | --- |
| `id` | string | derived | always `"<namespace>/<key>/<variant>"`; `upsert` sets it; a mismatch is "Id must be namespace/key/variant ('%s')." |
| `namespace` | enum | required | one of `unit`, `item`, `tile`, `skill`, `status`, `sfx`, `music`, `ui`; else "Unknown namespace '%s'." |
| `key` | string | required | `^[a-z][a-z0-9_]{0,39}$`; else `"Key '%s' must be snake_case (letters, digits, _; max 40)."` |
| `variant` | enum per namespace | first of the list | see variant table; else "Variant '%s' is not valid for namespace %s (allowed: %s)." |
| `path` | string | "" | starts with `res://assets/`; follows the folder pattern; file exists; loads as the namespace's resource type. Messages: "Path must start with res://assets/.", "Path must be %s (folder pattern).", "File '%s' does not exist.", "File '%s' does not load as %s." |
| `alias_of` | string | "" | `"<key>"` of the same namespace that resolves (template or manifest) and is not itself an alias. Messages: "Alias target '%s' is not a known %s key.", "Alias target '%s' is an alias (one hop only)." |
| `size` | `[int, int]` | `[]` = namespace default | each 8..2048; else "Size must be two whole numbers 8-2048." |
| `frames` | int | 1 | must be 1 (sprite strips reserved); else "frames must be 1 until sprite strips are built." |
| `origin` | enum `system`, `user` | `user` | same meaning as content origin (system rows refuse delete outside `begin_system_edit` style scope: `AssetCatalog.begin_system_edit()/end_system_edit()`). `upsert` outside the scope: a new row is always `user`; an existing row keeps its origin, a system row is refused ("'%s' is a system asset (origin system): edit it inside the system-edit scope.") and an explicit origin change is refused ("Origin changes go through AssetCatalog.promote / demote."). Inside the scope `upsert` may set the origin. `promote(id)` makes a row system; `demote(id)` makes it user and is refused while a test or seed names the id (`AssetScan.scan_files`); both return "" or why not |
| `note` | string | "" | 0..120 chars, free text (source, licence) |

Exactly one of `path` and `alias_of` is non-empty: "Set a path or an alias, not both." / "Set a path or an alias." Ids are unique: "Asset '%s' already exists."

### Namespaces, variants, folder pattern, defaults

| Namespace | Variants | Resource | Folder pattern for `path` | Default size (px) | Generated template | Fallback key |
| --- | --- | --- | --- | --- | --- | --- |
| `unit` | `token`, `portrait` | Texture2D (png, svg) | `res://assets/art/unit/<key>_<variant>.png` or `.svg` | token file 104x104 (composed texture 128x128), portrait 240x240 | UnitArt (keys `UnitArt.CLASS_KEYS`) | `unit` |
| `item` | `icon` | Texture2D | `res://assets/art/item/<key>_icon.png` or `.svg` | 96x96 | ItemArt (keys in `ItemArt.TEMPLATE_KEYS`, below) | `weapon` |
| `tile` | `v0`, `v1`, `v2`, `v3` | Texture2D | `res://assets/art/tile/<key>_<variant>.png` or `.svg` | 108x108 | TileArt (keys = snake_case `Terrain.Type` names plus `overlay_exit`, `overlay_poi`; `overlay_center` renamed 2026-10-17 by GRID12) | `floor` |
| `skill` | `icon` | Texture2D | `res://assets/art/skill/<key>_icon.png` or `.svg` | 64x64 | SkillArt (any skill family id) | `skill` |
| `status` | `icon` | Texture2D | `res://assets/art/status/<key>_icon.png` or `.svg` | 64x64 | StatusArt (any `StatusRegistry` id) | `status` |
| `sfx` | `stream` | AudioStream (ogg, wav) | `res://assets/audio/sfx/<key>.ogg` or `.wav` | - | none | silence |
| `music` | `stream` | AudioStream (ogg) | `res://assets/audio/music/<key>.ogg` | - | none | silence |
| `ui` | `icon`, `background` | Texture2D | `res://assets/art/ui/<key>_<variant>.png` | none (no size check) | none | blank |

`ItemArt.TEMPLATE_KEYS` (new const, the glyphs `_glyph` draws today plus fallbacks): `sword, greatsword, shortsword, dagger, hammer, axe, bow, staff, wand, tome, knuckles, shield, plate, leather, robe, ring, amulet, potion, elixir, bomb, weapon, misc` plus the `UNIQUE_ICONS` keys (`titan_warhammer`, `runed_staff`). A tile file for `v0` serves every variant that has no own file.

### Registry API (`AssetRegistry`, `RefCounted`, static)

| Function | Returns |
| --- | --- |
| `namespaces() -> Array[String]` | the 8 namespaces above |
| `variants(ns) -> Array[String]` | the variant list |
| `template_keys(ns) -> Array[String]` | generated keys (empty for sfx, music, ui) |
| `keys(ns) -> Array[String]` | template keys plus manifest keys, sorted, unique |
| `has_key(ns, key) -> bool` | key in `keys(ns)` |
| `resolve(ns, key, variant) -> Dictionary` | `{"source": "file" or "template" or "fallback", "key": resolved key after alias, "path": String}` |
| `texture(ns, key, variant, team = -1) -> Texture2D` | never null for texture namespaces (rule 3) |
| `stream(ns, key) -> AudioStream` | null when unresolved (sound is optional) |
| `default_size(ns, variant) -> Vector2i` | table above |

Content fields that hold keys and their namespace: class `art`, unit `art`, world character `art` (`unit`); item `icon_id` and item family `art` (`item`; `AssetScan.KEY_FIELDS` counts both as references for rule 7). Their option lists (`ContentSchema.options_of` "art" and "art_inherit", `WorldSchema.options_of`) become `AssetRegistry.keys("unit")` (with "" first for art_inherit). `ClassUnitValidator` message stays "Art '%s' isn't a known token/portrait key." but checks `AssetRegistry.has_key("unit", key)`. Item `icon_id` (commit 2, after ITEM1-L): "" or `AssetRegistry.has_key("item", key)`, message "Icon '%s' isn't a known item icon key.".

## Rules (logic lane)

1. Resolution order for `texture(ns, key, variant, team)`: (a) the manifest row `ns/key/variant` (for tiles also `ns/key/v0`); an alias row resolves its target once; (b) the generated template; (c) the fallback key's template (or blank texture for `ui`). A row whose file fails to load at runtime logs `push_warning("AssetRegistry: '%s' failed to load; using the placeholder.")` once per id per session (a static set) and continues with (b).
2. Cache: file textures cache in `SvgRaster`'s cache under `"file|<id>|<team>"`; template textures keep today's keys. `SvgRaster.clear_cache()` also clears the warned-once set.
3. Team overlay for `unit/token` files: the texture is composed, not drawn by the file: rasterise the token template WITHOUT the glyph (`UnitArt.token_svg(key, team, false)`, new bool param, default true) at scale 2 (128 px), then `Image.blend_rect` the file image resized to 104x104 (Image.INTERPOLATE_BILINEAR) at offset (12, 12). `unit/portrait` files are blended at full size over `UnitArt.portrait_backdrop_svg(team)` (new: the template's team backdrop only). One file therefore serves all three teams, and the spiked (hostile) and dashed (neutral) rims stay.
4. `UnitArt.token` / `portrait` and `ItemArt.icon` keep their signatures and delegate to the registry, so the 60 call sites do not change. `UnitArt.normalize_class` uses `AssetRegistry.has_key("unit", key)` (unknown key -> `unit`).
5. Item icon key precedence (`ItemArt.icon_key`, commit 2): item `icon_id` if `has_key("item", icon_id)`; else the gear-type derivation. The branch `return "shortsword" if eq.off_hand_category == "shortsword" else "sword"` is removed (HISTORY row 23: the shortsword off-hand category is deprecated; ITEM1 shrinks the category options to "", shield, orb, tome). `wpn_shortsword` keeps its icon through `icon_id: "shortsword"` written by S14-A1 (its item part), so `art_terrain_test_suite` line 123 (`icon_key(create_iron_shortsword()) == "shortsword"`) keeps passing unchanged. The item part therefore merges only after ITEM1-L and the S14-A1 item row.
6. Placeholder icons (DECISIONS "S14 baseline answers"): `SkillArt.icon(family_id) -> Texture2D` and `StatusArt.icon(status_id) -> Texture2D`, 32x32 viewBox rasterised at 2.0 (64 px), cached `"skill|<id>"` / `"status|<id>"`.
   - SkillArt: disc colour by the family's kind (ATTACK `#ef4444`, DEFEND `#94a3b8`, SUPPORT `#22c55e`, FOCUS `#eab308`, MOVE and DISENGAGE `#3b82f6`, REST `#64748b`, TARGET `#e2e8f0`, STATUS `#a855f7`), a white glyph per kind (sword, shield, cross, star, arrow, chevron, dot, ring, wave: one SVG path each), grade rim (novice single, advanced double, expert gold `#fbbf24`). No text in SVG (ThorVG text needs fonts). Unknown family id: kind `ATTACK` look with key `skill`.
   - StatusArt: disc green `#16a34a` for buffs, red `#dc2626` for debuffs (from `StatusRegistry` kind), one distinct white glyph per registry id in a `GLYPHS` dictionary (all 8 current ids; S12S adds 6 rows to it); an id without a glyph gets an up arrow (buff) or down arrow (debuff).
7. `AssetScan`: `ids_of`/`scan` count a manifest key as referenced when any content field from the schema contract holds it, or another manifest row aliases it. `AssetCatalog.remove(id)` is allowed when the row's key still resolves to a generated template afterwards (removing an override brings back the placeholder). For a manifest-only key (no template) it is refused while content references that key and variant, or another row aliases it: "Asset '%s' is used by %s; remove the references first." and changes nothing (user decision 2026-10-17, option A; checked per variant so removing one variant of a manifest-only key cannot silently fall back to the generic art).
8. Tool `tools/export_placeholder.gd` (headless, args `ns key variant [team]`): writes the template texture as PNG to the folder-pattern path (for `unit` `token`: the glyph layer only, cropped to the 104x104 inner square, i.e. the part a token file replaces) and prints `§ wrote <path> <w>x<h>`. Used by S14-A1 to make sample files that look like today's placeholders. Run through `tools/fc.sh` style `--headless -s`.

### Acceptance checks (rule-derived; suite `asset_pipeline_test_suite.gd`)

1. Every key held by shipped content (classes, units, world characters of every world, items' `icon_id`, skill families, `StatusRegistry` ids, `Terrain.Type` values) resolves: `texture(...)` is non-null and its size equals the composed size (unit token 128x128) or else `default_size`; a file whose own size differs from its row `size` (or the default) gives a warning in `warnings_for`, never an error.
2. `validate_entry` returns the exact message of each row of the field table for one bad entry per rule (namespace, key pattern, variant, path prefix, folder pattern, missing file, wrong type, alias unknown, alias chain, both or neither set, size, frames, duplicate).
3. In a sandbox manifest (`use_path(TestHelpers.sandbox("asset") + "/manifest.json")`, files written by the export tool into the sandbox): a row with a path yields `source == "file"`; deleting the file yields `source == "template"` and exactly one warning across two lookups.
4. An alias row resolves to its target's texture (same image data); an alias of an alias fails validation.
5. Two `texture` calls with equal arguments return the same instance; after `SvgRaster.clear_cache()` a new instance.
6. A unit token file override: the three team textures differ only outside the 104x104 inner square (sample pixel at (2, 64) differs per team, pixel at (64, 64) equal).
7. `UnitArt.normalize_class("no_such_key") == "unit"`; every `UnitArt.CLASS_KEYS` key is in `keys("unit")`.
8. Every `StatusRegistry` id has a `StatusArt` glyph (no arrow fallback for shipped ids); `SkillArt.icon` of every shipped family is non-null and 64x64.
9. `remove` of a row whose key has a template succeeds even while content names the key (the art falls back to the template); `remove` of a referenced manifest-only key (per variant, or aliased) is refused with the rule 7 message; an unreferenced user row is removed.
10. `validate_all()` of the shipped manifest is `{}`; `ContentCatalog.validate_all()` stays `{}`.

## Out of scope

Real art, audio playback (S14-L3), animation (S14-L2), sprite strips (`frames` > 1), Forge UI for the manifest (rows are added by seeds through `upsert`), icon use in the planner UI (the skill-tier picker is a separate task), world-layer art beyond the existing character `art` field, dojo-only textures.
