# Decisions: classes and units

Settled; do not re-litigate without asking the user. Scope: class budget and roster, class identities, units, passives, enemy scaling. Rows moved unchanged from `docs/DECISIONS.md` on 2026-10-17 (CLN-10), in their original order; append new rows at the end of the table. Index and global rules: `docs/DECISIONS.md`; superseded rows: `docs/decisions/archive.md`.

| Decision | Choice | Why |
| --- | --- | --- |
| Class balance | Equal stat budget (62) and growth (5/level) enforced by the catalog | Classes differ only by distribution, so balance is comparable |
| Unit variance | Authored spend pool (4 + level-1), exact | Same-class units differ without breaking budget |
| Mastery | Removed. Gear = class Proficiency dict. Traits = Passives granted by sources | Mastery was coupled to units; lore should grant traits |
| Passives | Generic lore-free templates in base catalog; sources reference them | Worlds stay modular |
| Enemy scaling | One base curve (class + tier + AI). Worlds set level and tuning deltas; "goblin" is lore | Same class behaves the same across worlds |
| Authored `power` | Absolute (tiers do not scale it) | Predictable for fixed/special units |
| Passives lifetime | Permanent by default; scripted fights/events may grant temporary ones for that fight/event | User 2026-10-15 |

| Portrait backdrops (2) (user 2026-10-27) | Every unit whose affiliation is known sits on its faction's backdrop, rank-and-file units included, so a mob's side reads at a glance; only a portrait whose affiliation is unknown (a generic class picture standing in for a unit without art) gets a plain unaffiliated backdrop; neutral groups (Wenn Tallow and Orsa's road people) get a new yellow-orange backdrop; an ash/goblin backdrop is wanted later, not a priority. | Every role attacks (user 2026-11-10) | Classes are balanced so every role keeps some offensive capability in a normal round: support- or heal-leaning roles may open with support, but no role is built for rounds of pure support. Reason: from Act 2 Cold Steel attack skills cost weapon durability while support skills and basics cost none (`docs/specs/ACTS23.md` 5.2), so durability must be a real cost for every class | User 2026-11-10 (Design Session chat) |
| Keystone themes (user 2026-11-10) | Every class has two keystone themes for its one keystone slot: **Cold Steel keystones are tied to weapons** (weapon families, techniques and masterwork gear, the Hearth side) and **Inoculated keystones are tied to corruption** (Strain, grafts and Calcification, the Slab side; installed by surgery). Example: the priest's Inoculated keystone carries the once-per-battle in-combat undo of a Flesh Breach (`docs/sessions/PK1_CORRUPTION.md` 3) | User 2026-11-10 (Design Session chat) |
