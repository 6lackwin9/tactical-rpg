# Decisions: classes and units

Settled; do not re-litigate without asking the user. Scope: class budget and roster, class identities, units, passives, enemy scaling. Rows moved unchanged from `docs/DECISIONS.md` on 2026-10-17 (CLN-10), in their original order; append new rows at the end of the table. Index and global rules: `docs/DECISIONS.md`; superseded rows: `docs/decisions/archive.md`.

| Decision | Choice | Why |
| --- | --- | --- |
| Class balance | Equal stat budget (62) and growth (5/level) enforced by the catalog | Classes differ only by distribution, so balance is comparable |
| Unit variance | Authored spend pool (4 + level-1), exact | Same-class units differ without breaking budget |
| Mastery | Removed. Gear = class Proficiency dict. Traits = Passives granted by sources | Mastery was coupled to units; lore should grant traits |
| Passives | Generic lore-free templates in base catalog; sources reference them | Worlds stay modular |
| Enemy scaling | One base curve (class + tier + AI). Worlds set level and tuning deltas; "goblin" is lore | Same class behaves the same across worlds |
| Authored `power` | Absolute (tiers do not scale it) | Predictable for fixed/special units |
| Passives lifetime | Permanent by default; scripted fights/events may grant temporary ones for that fight/event | User 2026-10-15 |

| Portrait grid 120 px (user 2026-10-26) | Game portraits pixelize to a 120 px grid (was 96) inside the 240 px frame (2x); every shipped portrait is re-run at 120 | The Aline expression test: at 96 px the eyes and mouth blur and hurt reads like angry; at 120 px each expression reads |
| Portrait backdrops and rims (user 2026-10-27) | Each portrait sits on its faction's backdrop in the "corner" style: darkest behind the face, brighter toward the frame's corners and edges (Hearth warm brown, Castellan deep red, Clerisy saturated dark violet, Guild rich dark green, corrupted violet-black, creatures cold dark teal; tunable); the figure's outer edge gets a rim highlight strong enough that dark hair separates from the backdrop, and portrait prompts ask for a thin bright rim light along the hair and shoulders | The faction tests: lighting alone left every backdrop alike; dark hair (Tess) blended where a highlighted one (Quell) read |
| Portrait reduction by source (user 2026-10-27) | Smooth sources (local Klein images) pixelize with a smooth downscale then a 14 families x 5 shades palette, which keeps thin facial detail (scars, veins, irises, spectacle rims); true pixel-art sources (the Gemini cast) keep the most-common-colour reduction and 10 x 4 that preserve their clean clusters; the tool picks by detecting a steady pixel grid; portraits only: exploration and combat sprites keep their chunky pixel style | A stage-by-stage test showed the detail loss comes from the per-cell vote and the small palette, not the 120 px size; the smooth path looks less blocky but reads far better for faces |
| Portrait backdrops (2) (user 2026-10-27) | Every unit whose affiliation is known sits on its faction's backdrop, rank-and-file units included, so a mob's side reads at a glance; only a portrait whose affiliation is unknown (a generic class picture standing in for a unit without art) gets a plain unaffiliated backdrop; neutral groups (Wenn Tallow and Orsa's road people) get a new yellow-orange backdrop; an ash/goblin backdrop is wanted later, not a priority. Rank-and-file portraits keep the face less defined and make the class and role prominent (armour, weapon, silhouette) | The Watch units fell back to the Hearth-lit class pictures and read as allies; yellow-orange is free now that the Guild reads strongly green |
