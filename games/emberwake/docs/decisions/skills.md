| Skill loadout (user 2026-10-15) | A unit has at most 5 class skills + 3 extra slots ACTIVE in combat; a character may own a longer skill list but sets the active loadout outside combat and cannot change it during combat. Basics counted separately | User 2026-10-15 |
| Skill model v2 (user 2026-10-15, supersedes the 'level 4-5 advanced version' idea) | A skill family has tiers 1-3 (basics up to 5) chosen at PLANNING time (higher tier = more AP + more power, limited by the unit's skill cap). Advanced versions are SEPARATE families with their own tiers 1-3, a higher base AP cost and extra effects (Greater Mend = Mend + cleanse/buff in one slot, freeing a slot). The active loadout (max 5 class families + 3 extra, basics separate) is set outside combat | User 2026-10-15; implementation: tiers reuse existing skill ids grouped by `family`+`tier` (strike/power_strike/heavy_blow ...) so old data and tests stay valid |
| M2c-2a1 skill families (2026-10-15) | Families group existing skill ids by `family`+`tier` (strike/power_strike/heavy_blow, guard/brace/fortress, focus/deep_focus); basics = strike & guard families + offhand_jab, need no slot; default active loadout = first 5 non-basic class-path families reached by level + up to 3 extra families; excess is owned but inactive; loadout locked from session start to dispose; passives/`learn_skill` may still add a skill mid-battle (auto-slots into a free extra slot); family rename carries sibling tiers and unit loadouts.
