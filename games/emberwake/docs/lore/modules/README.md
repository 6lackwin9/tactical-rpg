# Lore modules (index)

Status: open (user 2026-10-25). Lore and events as independent modules, the `3 lore` focus of
[OPEN_QUESTIONS.md](../OPEN_QUESTIONS.md) section 1: each module can be read and decided on its own, without
fleshing out the broader narrative; the narrative is fleshed out later by connecting approved modules. Format and
rules: [engine/docs/authoring/lore_modules.md](../../../../../engine/docs/authoring/lore_modules.md). The core story
(the spine, the slice's beats, the world logic the systems read) is a separate track and lives in
[CANON.md](../CANON.md) and the [story guide](../STORY_GUIDE.md), not here.
