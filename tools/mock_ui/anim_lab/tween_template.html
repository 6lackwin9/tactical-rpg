Kaelen in-between lab

Generated keyframes against in-betweens made by code. Every column in a clip runs for the same total time, so only the drawings differ. All frames are snapped to one shared palette with a hard alpha edge.

View
Methods. Keys: the generated keyframes only, each held for the time its in-betweens would take. Flow: dense optical flow between neighbouring keys; each in-between takes the nearer key's warped pixels, so nothing ghosts. Hybrid: the halberd is lifted out of every key, the body is in-betweened by flow, and one canonical halberd is drawn back as a rigid prop placed by the hand landmarks. Code: one stop frame moved by code only. Built by python3 -m tools.mock_ui.anim_lab.tween.
