# scripts/game_state

System: S13 (save/load schema, session state). Status: done (M3; save v2 in M4-L; save v3 in EXP1-L; save v4 in DLG1-L; save v5 in TRAV1-L; save v6 in TRAV2-L). Tests: `scripts/tests/save_test_suite.gd`, `scripts/tests/quest_runtime_test_suite.gd` (quest blob and migration), `scripts/tests/exploration_test_suite.gd` (v3 keys, migration, rolls), `scripts/tests/dialogue_test_suite.gd` (v4 gold and shops), `scripts/tests/travel_test_suite.gd` (v6 party supplies), `scripts/tests/save_compat_test_suite.gd` (one sample save per version in `scripts/tests/fixtures/saves/`, decoded every gate run; regenerate with `tools/gen_save_fixtures.gd`).

- `game_state.gd` (`GameState`): world, location (a QUALIFIED location id or ""), party, flags (`[a-z0-9_.]` to bool/int/String), the structured quests blob (qualified quest id to `{state, objective}`, checked by `QuestRules.validate_blob`), `loot_claimed` (unique qualified loot ids, saved sorted), and the exploration keys `position` ([x, y], [-1, -1] = no map), `explore` ({steps, next_at, loc_steps, last_safe}), `rng_seed`, `rolls` (stream to count), and `shops` (shop qid to {item id: sold count >= 1}, DLG1-L; party gold lives in `PartyState.gold`); `to_dict` / `from_dict` / `validate` / `equals`.
- `game_rolls.gd` (`GameRolls`): per-save deterministic streams (`roll`, `range_i`, `chance`, `pick`); roll n of stream s is seeded with `hash([rng_seed, s, n])`. Streams `explore` (EXP1) and `travel` (TRAV1).
- `save_game.gd` (`SaveGame`): versioned envelope `{format, version: 5, saved_at, game_state}`, `user://saves/slot_<n>.json`, `set_base_dir` override for tests, atomic write (tmp then rename), `read` never returns a partial state.
- `save_migrations.gd` (`SaveMigrations`): from_version to from_version+1 table with the built-in steps 1 to 2 (keeps valid quest entries, drops the rest with one warning each, adds `loot_claimed: []`) and 2 to 3 (exploration defaults, `rng_seed` from the hash of the v2 state, `location_id` qualified when it resolves, else "") and 3 to 4 (`party.gold: 0`, `shops: {}`) and 4 to 5 (world clock `time: 0`) and 5 to 6 (`party.supplies: PartyState.SUPPLIES_START` (10) when the party is an object); `reset()` restores the built-in table; newer saves refused, unknown `game_state` keys dropped with warnings.
- `new_game.gd` (`NewGame`): `create(world_id, base_unit_ids, p_seed := -1)` returns `{state, errors}`; `p_seed` >= 0 is the save's `rng_seed`, -1 = from the clock; party gold = `DialogueRules.start_gold(world_id)`, party supplies = `TravelRules.start_supplies(world_id)` (TRAV2-L: nearest manifest `start_supplies` >= 0, else 10).
- `json_util.gd` (`JsonUtil`): JSON-safety check, float-to-int normalise, deep equality.

Tests and sandboxes must call `SaveGame.set_base_dir` and never touch the real `user://saves`.

`from_dict` records raw type problems in `load_problems`; `validate()` reports them, so damaged `quests` / `loot_claimed` blobs are refused, never coerced.
