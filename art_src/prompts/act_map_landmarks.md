# Act maps: one landmark per location (runnable prompt file)

Art/UI batch 2026-11-13 (Tushar: "an act map listing all the regions with their own artwork on the map"). Every
location on the three act maps gets its own landmark: a small bird's-eye miniature of the place, drawn on the
magenta key and placed on the act's map instead of the generic kind pin. The hub (`00`) is one landmark shared by
all three acts. Sources: the shipped Act 1 data (`worlds/sunk_ward/locations.json`) and the canon act maps
(`lore/background/{sunk_ward,upper_bastion,mantle_fissure}_campaign_map.md`, `CANON.md` 2.1-2.2).

How to run (`tools/portraits/generate.py` reads each section's text block as the whole prompt: the reference line first when there is one, as the studio's rule 4 asks, then the style block, then the landmark):

1. The hub first, with no reference: `generate.py run <model> lm_sluice_undercroft --n 2 --no-ref --prompts art_src/prompts/act_map_landmarks.md`
   (or the Drive queue: `artqueue.py request lm_sluice_undercroft --prompts art_src/prompts/act_map_landmarks.md --no-ref --n 2 --route other`).
   Pick the take and save it as `art_src/lm_sluice_undercroft.png`; it sets the scale, angle and palette of the set.
2. Then the rest: `generate.py run <model> <ids...> --n 2 --prompts art_src/prompts/act_map_landmarks.md` (or `artqueue.py request
   <ids...> --prompts ... --n 2 --route other`). Each section's
   `reference:` line sends the picked hub, so the set stays consistent.
3. Cut each pick with `python3 art_src/prompts/cut_ai_sheets.py landmark art_src/<id>.png <location_id>`: the magenta is
   keyed out and the landmark is box-downscaled into **96 x 96** (drawn at 48 logical pixels on the 640 x 360 map) at
   `games/emberwake/assets/map/landmarks/<location_id>.png`. The game does not draw landmarks yet: Outbox `AO-01`.

Check every take: one landmark only, nothing touching the frame edge, no magenta or pink inside it, readable when
shrunk to 48 pixels, and it matches the hub in angle, outline weight and palette.

The shared style block (already inside every prompt below; edit it here and in each section together):

```txt
Pixel art map landmark for the district map of a gothic dark fantasy tactical RPG, in the style of detailed 16-bit SNES/GBA-era RPG world maps. Square 1:1 image. Exactly one landmark: a small, self-contained miniature of the place seen from high above at a three-quarter bird's-eye angle (about 45 degrees), like a diorama piece standing on a small irregular patch of its own ground, centred, filling about two thirds of the frame, with clear empty space all around it. It must read at a glance when shrunk to 48 pixels: one bold silhouette, a few large shapes, strong value contrast between the landmark and its ground, clear dark outlines, hand-placed pixel clusters, a limited palette with 4 shades per colour, light dithering. A sunless city under falling ash, lit only by lanterns and furnaces: soot-black stone, wet slate, scavenged iron and boiled leather; bright colour only on small accents (lantern glow, a banner, a glowing vent). Colours only from this palette and its shades: void black #0a0b10, damp basalt #14171f, wet slate #1e232d, rotting oak #2c221e, scavenged iron #4b5563, polished steel #9ca3af, bleached linen #d9cbb4, cinder ash #6b7280, boiled leather #92400e, tallow amber #d97706, candle gold #fbbf24, arterial red #e11d48, rust crimson #991b1b, blight violet #9333ea, resonant orchid #c084fc, salt cyan #06b6d4. Any violet glow stays a deep blue-violet, never pink. Key light from the upper left, a thin warm rim light. Every light source sits inside the landmark's silhouette: no glow, halo, sparks or smoke spilling past its outline onto the background. No people except tiny specks, no text, no letters, no signs with writing, no labels, no frame, no border, no UI, no cast shadow beyond the ground patch. Background: flat, solid pure magenta (#FF00FF) filling the whole image edge to edge, no gradient, no vignette, no texture; no magenta, pink or purple anywhere in the landmark itself.
```
