# S14-A2: placeholder SFX files and manifest rows

Status: approved (user 2026-10-17) (design-brainstorm 2026-10-17; DECISIONS content-forge "S14 baseline answers")
Depends on: S14-L3 commit 1 (tool, `SoundEvents`), S14-L1 commit 1 (manifest)
Lane: asset
Touches: `assets/audio/sfx/*.wav` (generated), `data/assets/manifest.json`, seed `data/seeds/s14_a2.gd`, `data/seeds/README.md`

## Goal

Give every combat and UI sound key a generated placeholder blip so the audio path is exercised end to end. Real sounds replace the files later by a new file plus a changed `path` (same key), with no code change. Source and licence of real sounds are a later user choice; generated files have no licence issue.

## Schema contract

None (S14-L1 manifest fields).

## Assets

Generate each file with `tools/gen_placeholder_sfx.gd` passing the row of the table below as its args (wave, hz from, hz to, ms, envelope `decay` for fast decay, `fade` for fade in/out, `slow` for slow decay, gain dB 0 unless listed; all values are placeholders), then upsert one row per key: `namespace: sfx`, `variant: stream`, `path: res://assets/audio/sfx/<key>.wav`, `origin: user`, `note: "placeholder blip (generated)"`.

| Key | Wave | Frequency (Hz) | Length (ms) | Envelope |
| --- | --- | --- | --- | --- |
| `hit` | noise | - | 80 | fast decay |
| `crit` | noise + sine | 220 | 140 | fast decay |
| `mitigated` | sine | 180 | 90 | fast decay |
| `heal` | sine sweep up | 440 to 660 | 220 | fade in/out |
| `buff` | sine | 523 | 160 | fade in/out |
| `debuff` | sine sweep down | 330 to 220 | 200 | fade in/out |
| `defend` | sine | 150 | 120 | fast decay |
| `move_step` | noise | - | 40 | fast decay, quiet (-12 dB) |
| `defeat` | sine sweep down | 260 to 110 | 400 | slow decay |
| `ui_click` | sine | 880 | 30 | fast decay, quiet (-12 dB) |
| `ui_confirm` | sine | 988 | 60 | fast decay |
| `ui_back` | sine | 660 | 50 | fast decay |
| `ui_error` | square | 140 | 120 | fast decay |

## Acceptance (rule-derived)

1. `AssetCatalog.validate_all()` is `{}`; one row per key of the `SoundEvents` key table, no extra keys.
2. `SoundBank.has(key)` is true for every key in the table; each stream is an `AudioStreamWAV` with the listed length within 5 ms.
3. Seed listed in `data/seeds/README.md`.

## Build notes (planner 2026-10-17)

- The seed writes the files itself through `PlaceholderSfx.write`, the same generator and arguments as `tools/gen_placeholder_sfx.gd`, then upserts the rows, so one `tools/fc.sh run data/seeds/s14_a2.gd` rebuilds everything; it prints a length check per key (all 13 within 5 ms).
- Table to args: "noise + sine" is wave `noise_sine`, "-" frequency is 0, fast decay `decay`, fade in/out `fade`, slow decay `slow`, quiet -12 dB.
- The `.wav.import` files are committed (edit/trim and normalize off, so lengths stay exact).

## Out of scope

Music, real sound files, per-skill sounds, volume tuning.
